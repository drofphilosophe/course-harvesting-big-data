Measuring Agricultural Productivity

Agricultural Productivity

How should we measure agricultural productivity?

  • Productivity is a measure of how inputs are converted into outputs

What are inputs to agriculture?

  • Land
  • Labor
  • Water
  • Machinery (capital)
  • Fertilizer
  • etc

Measuring Agricultural Productivity

How do we measure agricultural productivity?

  • One measure is Total Factor Productivity
  • Index measuring how efficiently agricultural inputs are transformed into agricultural outputs
  • Effectively a ratio of output to inputs
  • Easy when there is one input
  • More difficult when there are many

TFP in Practice

In practice we measure TFP as a function

  • Hold other inputs/factors constant
  • TFP is the “left over” productivity

What is the difficulty with this approach?

  • How do we make sure farmers hold inputs constant? (we can’t)
  • Other factors (e.g., weather) are impossible to hold constant
  • Do we care about productivity in the lab or on real farms?

Estimating TFP

Estimating TFP is an empirical modeling problem

  • Collect data on all factors we think influence crop growth
  • Across many farms and many years
  • Use of inputs and other factors will vary across observations
  • Use this variation to isolate the impact of each factor on output
  • Combine this with actual input use to predict output for each observation
  • TFP is the “residual” (true value minus prediction)

Challenges with Measuring TFP

  • Suppose we want to compute the change in TFP for many countries over time
  • We’ll use the method I outlined
    • Collect data on output, inputs, and other factors
    • Use it to construct an empirical model of productivity
    • TFP is the residual unexplained by the model
  • What challenges might we encounter?
  • What might you do to address those problems?

Some Challenges Measuring TFP

Some challenges measuring TFP using observational data

  • Consistency in measurement both across time and space
  • Unmeasured factors (e.g., intensity of rain)
  • Unmeasured quality of inputs and output
  • Substitution between inputs
  • Crop switching
  • Many more!

Is Measuring TFP Impossible?

  • There are many ways our estimates of TFP could go wrong
  • No set of estimates is “perfect”
  • Should we just give up?
  • TFP estimates provide valuable information, even if not “perfect”
  • Do the best job we can
  • Continue to improve (better data, models, etc)

Consistency of data is important for measuring TFP across countries and over time

  • Ideally measure output using methods that allow for comparing measurements
    • Across all countries
    • Across time
  • Include the majority of countries
  • Include a wide array of agricultural products

United Nations FAOSTAT Data

The UN collects and reports the FAOSTAT Data

  • Annual measurements of agricultural production
  • Consistent methods across over 200 countries/territories
  • Output measurements for nearly 300 types of output
  • Long time series of measurements (starting in 1961)

Available at https://www.fao.org/faostat

On Google Drive in Data/FAO

Summary of FAOSTAT

Each observation is a combination of

  • Year
  • Country
  • Agricultural output type
  • Measurement

FAOSTAT Measurements - Crops

FAOSTAT measures

Crops

  • Total area of land harvested (ha)
  • Production quantity (mt)
  • Yield (mt/ha)

Measurements for both primary crops (soybeans) and refined goods (soybean oil)

FAOSTAT Measurements - Livestock

FAOSTAT Measures

Livestock

  • Number of animals
  • Production quantity (mt)
  • Yield (mt/animal)

How do you do this with ggplot?

Using ggplot

  • You create visualizations with ggplot
  • Always starts with the ggplot() function
    • Arguments to this function are inherited by all layers
  • Add layers and other elements using the + operator
  • Arguments to layers override inherited arguments

Common ggplot layers

Layers add visual elements to your visualization

  • Scatter plot geom_point()
  • Line plot geom_line()
  • Smoothed line geom_smooth()
  • Many, many more

Create a visualization

  • Year on the horizontal axis (x aesthetic)
  • Your measurement (Value) on the vertical (y aesthetic)

Provide data and aesthetics to ggplot()

ggplot(
  data=faostat_brazilnuts,
  mapping=aes(x=Year,y=Value)
  ) +
  geom_line()

Create a visualization

  • Year on the horizontal axis (x aesthetic)
  • Your measurement (Value) on the vertical (y aesthetic)

Provide data and aesthetics to layers

ggplot(
  data=faostat_brazilnuts
  ) +
  geom_line(
    mapping=aes(x=Year,y=Value)
  )

Improving the visualization

Good visualizations are clear and self-contained

  • Informative axis labels
  • Clear what is being plotted
  • Use a legend where appropraite

An improved visualization

ggplot(
  data=faostat_brazilnuts,
  aes(x=Year,y=Value)
) +
  geom_line() +
  labs(
    x="Year",
    y="Production (mt)",
    title="Annual Brazil Nut Production",
    subtitle="Brazil 1990 - 2010",
    caption="Source: United Nations FAOSTAT"
  ) -> viz_1

Adding layers

Adding Layers

  • Add additional layers using the + operator
  • Each stacks on top of the previous one

Modifying Layers

  • Modify the appearance of an entire layer with layer properties
  • Arguments to layer functions outside the aesthetic
  • Available properties depend on the layer type

Adding Layers - Example

ggplot(
  data=faostat_brazilnuts,
  aes(x=Year,y=Value)
) +
  geom_line(color="black",linewidth=1) +
  geom_smooth(color="blue",linewidth=1.2)
